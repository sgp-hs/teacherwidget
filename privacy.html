개인정보처리방침

최종 수정일: 2026년 9월 15일

TeacherWidget은 사용자의 개인정보 및 Google 사용자 데이터를 중요하게 생각합니다. 본 방침은 TeacherWidget이 Google API 등 외부 서비스에 접근할 때 어떤 정보를 이용하고, 해당 정보를 어떻게 처리하는지 설명합니다.

1. 이용하는 정보

사용자가 Google 계정 연결 기능을 사용하는 경우 TeacherWidget은 다음 정보에 접근할 수 있습니다.

  • Google 계정의 기본 계정 정보
  • Google Calendar 일정 정보
  • TeacherWidget에서 사용하는 Google Calendar 관련 식별 정보
  • Google Tasks 할 일 정보
  • TeacherWidget에서 사용하는 Google Tasks 목록 관련 식별 정보

TeacherWidget은 프로그램 기능 제공에 필요한 범위에서만 해당 정보에 접근합니다.

2. Google 사용자 데이터의 이용 목적

Google 사용자 데이터는 다음 기능을 제공하기 위한 목적으로만 사용합니다.

  • TeacherWidget 일정과 Google Calendar 일정 동기화
  • 일정 등록, 수정 및 삭제
  • TeacherWidget의 해야 할 일과 Google Tasks 동기화
  • 할 일 등록, 수정, 완료 및 삭제
  • Google 계정 연결 상태 유지

Google 사용자 데이터는 광고, 마케팅, 사용자 프로파일링 또는 앱 기능과 무관한 목적으로 사용하지 않습니다.

3. 데이터 저장

TeacherWidget은 별도의 TeacherWidget 클라우드 서버를 운영하지 않습니다. 프로그램 설정, 카드 배치, 테마, 메모, 일정·할 일 동기화 정보 및 Google 인증에 필요한 정보는 기본적으로 TeacherWidget을 실행하는 사용자의 PC에 로컬로 저장됩니다.

Google Calendar 및 Google Tasks에 저장되는 정보는 Google 시스템에 보관되며 Google의 개인정보처리정책이 적용됩니다.

4. 제3자 제공 및 판매

TeacherWidget은 Google API를 통해 제공받은 사용자 데이터를 판매하지 않습니다. 또한 앱 기능 제공에 필요한 Google API 통신을 제외하고, Google 사용자 데이터를 광고업체 또는 기타 제3자에게 제공하지 않습니다.

5. Google API 데이터 사용

TeacherWidget은 Google API를 통해 받은 사용자 데이터를 사용자가 직접 요청한 기능을 제공하기 위한 목적으로만 사용합니다. Google API를 통한 데이터 이용은 Google API Services User Data Policy 및 해당 정책의 Limited Use 요구사항을 준수하는 범위에서 이루어집니다.

6. 계정 연결 해제

사용자는 언제든지 자신의 Google 계정 설정에서 TeacherWidget에 부여한 접근 권한을 철회할 수 있습니다. 접근 권한이 철회되면 TeacherWidget은 해당 Google 계정을 이용한 Calendar 및 Tasks 동기화를 더 이상 수행할 수 없습니다.

TeacherWidget이 사용자의 PC에 저장한 로컬 프로그램 데이터 및 인증 관련 데이터는 사용자가 해당 파일 또는 프로그램 데이터를 삭제하여 제거할 수 있습니다.

7. 데이터 보관 및 삭제

TeacherWidget의 로컬 데이터는 사용자가 프로그램을 사용하는 동안 해당 PC에 보관될 수 있습니다. 사용자가 TeacherWidget의 로컬 데이터 또는 프로그램을 삭제하면 해당 PC에 저장되어 있던 TeacherWidget 데이터도 제거할 수 있습니다.

Google Calendar 또는 Google Tasks에 저장되어 있는 데이터는 사용자의 Google 계정에서 직접 관리 및 삭제할 수 있습니다.

8. 개인정보처리방침의 변경

TeacherWidget의 기능 또는 Google API 사용 방식이 변경되는 경우 본 개인정보처리방침도 변경될 수 있습니다. 중요한 변경사항이 있는 경우 본 페이지의 최종 수정일을 갱신합니다.
